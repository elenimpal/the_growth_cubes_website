# Τεκμηρίωση προσβασιμότητας — The Growth Cubes

Η τεκμηρίωση αφορά τον τοπικό κώδικα του ιστοτόπου https://www.thegrowthcubes.com/ και το στιγμιότυπο της δημοσιευμένης αρχικής σελίδας που ελέγχθηκε στις 13 Οκτωβρίου 2026. Δεν έχει πραγματοποιηθεί ανάπτυξη στην παραγωγή.

Στόχος: WCAG 2.1 A και AA, σχετικές απαιτήσεις EN 301 549 V3.2.1 κεφαλαίου 9, και έλεγχος εφαρμογής κεφαλαίων 10 και 12. Η πλήρης συμμόρφωση παραμένει μη τεκμηριωμένη μέχρι να ολοκληρωθούν οι εκκρεμείς έλεγχοι και ο έλεγχος παραγωγής.

## Πεδίο και αλλαγές

Αρχικά υπήρχε μία δημόσια σελίδα (index.html), styles.css, script.js και ένα WebM που εμφανίζεται σε δύο διακοσμητικά φόντα. Προστέθηκαν accessibility.html και forms.js. Δεν υπάρχουν λογαριασμοί, αγορές, πίνακες δεδομένων, διάλογοι, υπηρεσία αποστολής φορμών ή δημόσιοι σύνδεσμοι λήψης εγγράφων. Δεν εντοπίστηκαν τρίτα widgets ή εξωτερικά scripts. Οι εξωτερικοί κοινωνικοί σύνδεσμοι είναι εκτός πεδίου.

Διορθώθηκαν ονομασίες πεδίων, αναγνώριση απαιτούμενων στοιχείων, επικοινωνία σφαλμάτων, εστίαση, mobile menu, χρωματική αντίθεση, κίνηση και η προσαρμογή υπηρεσιών σε μικρές οθόνες. Διατηρήθηκαν τα κείμενα, οι προορισμοί συνδέσμων και η βασική ταυτότητα. Η εμφάνιση έγινε φωτεινότερη όπου απαιτούνταν αντίθεση. Σε κινητά/μειωμένη κίνηση οι υπηρεσίες παρουσιάζονται σε κατακόρυφη λίστα. Στον υπολογιστή διατηρείται η κύλιση με εναλλακτική ανάγνωση ως λίστα.

Οι παλιές φόρμες ήταν επίδειξη. Τώρα προετοιμάζουν προσχέδιο email χωρίς ισχυρισμό επιτυχούς αποστολής ή εγγραφής. Η διεύθυνση hello@thegrowthcubes.com υπήρχε ήδη στον κώδικα· η πραγματική λειτουργία του γραμματοκιβωτίου χρειάζεται επιβεβαίωση από τον ιδιοκτήτη.

## Αρχεία

- ACCESSIBILITY_AUDIT.md: μητρώο ευρημάτων και 50 κριτήρια A/AA.
- AUTOMATED_TEST_RESULTS.md: πραγματικές εκτελέσεις και περιορισμοί εργαλείων.
- MANUAL_TEST_CHECKLIST.md: ακριβείς διαδικασίες ανθρώπινου ελέγχου.
- REMEDIATION_LOG.md: αλλαγές και αντιστοίχιση κριτηρίων.
- DYPA_EVIDENCE_PACKAGE.md / .html / .pdf: συνοπτική τεχνική αναφορά προς συμπλήρωση.
- OUTSTANDING_ITEMS.md: προϋποθέσεις πριν την τελική υποβολή.
- reports/: πρωτογενή JSON, Lighthouse HTML και πραγματικά screenshots.

Για υποβολή: ολοκληρώστε τις εκκρεμότητες, εγκρίνετε/δημοσιεύστε την έκδοση, επανελέγξτε την παραγωγή και ενημερώστε την αναφορά και τη δήλωση. Το σημερινό πακέτο είναι τεκμηρίωση ανάπτυξης, όχι βεβαίωση τελικής συμμόρφωσης παραγωγής.

## Επανάληψη ελέγχων

Απαιτούνται Node >=24.8 και εγκατεστημένο Google Chrome. Στο υπάρχον macOS υπάρχει Node 24.21.0. Χρησιμοποιήστε αυτό το runtime (π.χ. nvm use 24.21.0).

```sh
npm ci
npm run test:html
npm run test:a11y
npm run test:lighthouse
node tools/accessibility/contrast.cjs
python3 tools/accessibility/print-report.py
node tools/accessibility/evidence-pdf.cjs
```

Τα εργαλεία είναι μόνο development dependencies. Η ιστοσελίδα δεν απέκτησε frontend framework ή build pipeline. Το audit δημιουργεί προσωρινό HTTP server, ελέγχει το production URL μόνο για ανάγνωση και δεν στέλνει φόρμες.
